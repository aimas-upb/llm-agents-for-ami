Fast Path — Signifier Memory

A prior signifier matches the current intent (structural filter + SHACL context validation). The BehaviorTree is recovered directly from memory — no LLM call needed. Result: 7.3× speedup (2449 ms → 337 ms).

🤖
LLM Path — GPT-4o BT Planner

No prior signifier exists (cold start). The InteractionSolver asks GPT-4o to generate a BehaviorTree JSON plan from the WoT affordance context. On success, the plan is recorded as a new signifier for future reuse.

🌐
Community Experience Sharing

Agents query a cross-environment community via XMPP. Signifiers from Lab308 are transferred and adapted to HomeBench Home 17 with correct affordance URL rewriting — achieving 100% task success and 27% latency reduction.

Key Technical Contributions

Four tightly integrated components from the EMAS 2026 paper

01
🔗

HMAS Integration Pipeline

Automatically converts HomeAssistant device configurations into W3C WoT Thing Descriptions, then lifts these into an HMAS-compliant Hypermedia Environment via the Yggdrasil platform. Each device becomes a semantically typed artifact with discoverable affordances, enabling agent-level capability reasoning.

Paper § 3.1
02
🤖

Hybrid Agent Architecture

Three SPADE agents (UserAssistant, EnvExplorer, InteractionSolver) use deterministic state machines for all lifecycle management, with controlled LLM injection only at specific decision points. This avoids unpredictable black-box behavior while preserving the expressiveness of LLM reasoning for planning.

Paper § 3.2–3.4
03
🧠

Signifier Memory Engine

Records successful plans as signifiers: structured intent + affordance URI + payload hint + SHACL environmental conditions. At planning time, a two-stage matcher (structural filter then SHACL context validator) retrieves matching past experiences, enabling a 7.3× latency reduction (2449 ms → 337 ms) on warm starts with only 5 LLM calls vs. 18 on cold start.

Paper § 4
04
🌐

Community-Based Experience Sharing

Agents query a cross-environment peer community via an XMPP-based protocol. Signifiers from one environment (Lab308) are transferred and structurally adapted to a different environment (HomeBench Home 17) with correct affordance URL rewriting, achieving 100% task success and 27% latency reduction on transfer tasks.

Paper § 5

Interactive Demo

Three reproducible scenarios — run locally with the CLI runner

Sequence 2

Environment Discovery

Agents boot, EnvExplorer crawls the Yggdrasil HMAS environment, discovers all workspaces and WoT artifacts, and builds the internal capability map. No user interaction — shows the startup and discovery pipeline.

python tests/manual_test_full_flow_plan.py --sequence 2
Sequence 3 — Flagship

Explicit + Implicit Request Cold Start

Four interaction types in one session:

  1. List active devices (query to EnvExplorer)
  2. Query light state
  3. Explicit goal: BT planning → execution → signifier recording
  4. Implicit goal: LLM-path planning → user approval → execution → recording
python tests/manual_test_full_flow_plan.py --sequence 3 --clear-signifiers
Sequence 4

Experience Reuse ⚡ Fast Path

Requires signifiers from Sequence 3. Repeats the implicit request — the solver skips LLM planning entirely, recovers the BehaviorTree from Signifier Memory, and executes directly. Demonstrates the 7.3× speedup in practice.

python tests/manual_test_full_flow_plan.py --sequence 4
